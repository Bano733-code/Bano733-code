# 🚀 Featured Projects

| Project | Description |
|---|---|
| 🧬 **Gene2Trials Navigator** | AI-powered biomedical discovery platform connecting genes, diseases, drugs, clinical trials, and scientific literature using biomedical APIs including MyVariant, OpenTargets, ChEMBL, ClinicalTrials.gov, and PubMed. |
| 🧬 **AI Biomarker Discovery Platform** | Machine learning platform for transcriptomic biomarker discovery featuring data preprocessing, differential expression analysis, feature selection, ML classification, explainable AI with SHAP, and biological interpretation. |
| 🧬 **Single-cell RNA-seq Analysis Pipeline** | Complete single-cell RNA sequencing workflow including quality control, normalization, highly variable gene selection, PCA, UMAP visualization, clustering, marker gene identification, and biological interpretation using Scanpy and AnnData.| 
| 🧬 **Gene Sequence Alignment Toolkit** | Python implementation of classical bioinformatics algorithms including Needleman–Wunsch, Smith–Waterman, Dot Matrix, and Word Method for sequence comparison. |
